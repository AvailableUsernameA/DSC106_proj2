Proposition: Daniel is a better police officer comparing to Mathew

FOR the Proposition

Design Decisions and Rationale:

  • Choose count instead of ratio: I found both of them have 75 complaints. So we don't need to worry about ratio. To avoid people being suspect for overall count, I put the information on the top of the graph as grey text. I think this make the plot seems more precise and so more persuasive. Without specifying the overall count, it is easy for people to develop suspect that Daniel has more complaints. I will scale it to 2 because it is true that both officers have 75 complaints.
  • Data: To investigate on how to show Daniel outperforming Machew, I count the number of complaints for different 'board_disposition' and 'outcome_description' for each individuals. I found that Daniel has more exonerated cases and less unsubstantiated cases without arrest than Mathew does, which would make Daniel seems a better police officer. So I put them in the first plot. I think this can be scaled to -0.5 because all data are true but I only displayed part of the data. The problem here is that I can't display substantiated or unsubstantiated with arrest otherwise it would be easy to find that the plot is deceptive. But the blank still makes the plot a little suspective. I also considered deleting unsubstantiated directly, but in this way the plot contains too little information.
  • Bar plot following rules: The bar plot follows the rules of building a good plot. It has the same scale over axis and start from 0. The summations are in the right place corresponding to its value. Different colors for different people and use similar colors for the same people but different outcomes. As a bar plot, it is also easier for people to read. I made this decision because I believe for seasoned readers it is very easy find tricks like different scales and this could make them suspect the reability of the plot. By showing chosen data in a good plot, it can make the data seems more reliable. I would scale this to 2. I also considered using ratio and pie plot. But to make the plot more professional and reliable, I followed the instructions for a good visualization and still chose bar plot.

I wish they can draw the attension quickly so when people read them first and then plot they would find the conclusions are true and agree on the proposition. The conclusions are totally true, but still tries to lead people's opinion. it has scale -0.5. I tried a version without it but it comes that it would take more time to draw the conlusions.

Final Reflection

I dicide to make the plot deceptive using data at a very start point because I think it can be easy for seasoned readers to find the trick once they carefully read a plot with different scales and they would be suspect if I hide some important numbers. So the most difficult part here is to choose the right data. Plotting is relatively simple. I just follow the instructions for good plots.

It is kind of surprising to see how the data differs so much given they received seem number of complaints. But it may just because the sample size is small. I think "ethical analysis and visualization" indicate that we shouldn't use visualization to lead a wrong conclusion. It gets worse when this may harm people. I personally think these plots are not so ethical because it may harm the two officers I chose.

I would say both plots are misleading. Both of them used part of data and have annotations as sub conclusions to lead reader's idea. They only show the data supporting their argument. An acceptable choice should demonstrate all data necessary when making the conclusion.
